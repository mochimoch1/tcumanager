# tcumanager

大学のWebClassから課題情報を自動スクレイピングし、優先順位付けから完了管理までを一元化するタスク管理アプリケーションです。

## 開発の背景
大学のポータルサイト（WebClass）はUIが複雑で、課題の有無を確認するたびにログインし、複数のページを遷移する必要がありました。この非効率なルーチンワークを解消するため、スクレイピングを用いて「PCを起動するだけで、今日のタスクと重要度が可視化されている状態」を実現しました。

## プロジェクト構成
- `main.py`: アプリケーションの中心。スプレッドシートとの同期、通知判定、メインロジックを統括。
- `scraper.py`: Playwrightを使用したWebClassからの課題情報抽出（自動ログイン・セッション管理含む）。
- `app.py`: Streamlitを用いたフロントエンド。達成度ゲージやタスクのカード表示UI。
- `manager.py`: スプレッドシートとのCRUD処理および優先順位計算ロジック。
- `input_form.py`: 補助的なタスク手動登録機能（Tkinter）。

## 主な技術
* **Language:** Python
* **Frontend:** Streamlit
* **Web Scraping:** Playwright
* **Database:** Google Sheets (gspread)
* **Automation:** LINE Messaging API (期限通知)

## 主な機能
* **完全自動同期:** WebClassのダッシュボードから課題を抽出。既存の課題との重複を防ぎつつ、未完了課題を自動取得。
* **優先スコアの算出:** 期限・重要度・見積もり工数から、取り組むべきタスクを自動でランキング表示。
* **達成感の可視化:** 専門科目・教養科目の分類や、達成度ゲージによる進捗表示で学習のモチベーションを維持。
* **プッシュ通知:** 期限が迫った課題をLINEへ自動通知。

## 今後の展望
* **AIによる難易度推定:** 詳細な課題内容をAIで解析し、課題の難易度や必要な工数を自動的に推定・スコアリングする機能の実装。
* **クラウド定期実行:** GitHub Actionsと連携し、ローカルPCを起動していなくてもクラウド上で常に最新の状態を維持。
