# tcumanager

大学のタスク管理を効率化するために開発した自動スクレイピング・タスク管理アプリケーションです。

## 💡 開発の背景
大学のマイページを毎回手動で確認する手間を省き、タスクの取りこぼしを防ぐために開発しました。

## 🛠 プロジェクト構成
- `scraper.py`: 大学サイトからの情報抽出を担当
- `manager.py`: 取得したデータの管理・処理ロジック
- `app.py` / `main.py`: アプリケーションの実行およびインターフェース
- `input_form.py`: ユーザー入力等の補助機能
